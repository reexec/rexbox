## rexbox v0.0.31 (English)

The changes since **v0.0.30** (issue #87). **Title code can announce a wait that is not a kernel wait**: for its length the guest locks are put down, and the stall report shows it as a wait.

Issue: #87, `rexbox_guest_wait_begin`/`rexbox_guest_wait_end` (C API) and three kernel probe checks (`245ed3f`).

For consumers: **no code change is needed**; only a consumer that wants the new functions calls them. reexec/reCT3#52 uses them for CRI's safe-thread handshake.

Verified: rexbox Release with 0 warnings, CTest 4/4, kernel probe 106 checks; reCT3: no deadlock in 48 hidden demo runs (one in 48 before the fix), drives fine.

Implemented by Antigravity; designed, reviewed and measured by Claude.

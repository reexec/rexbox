## rexbox v0.0.9

이전 릴리스 **v0.0.8** 이후의 변경입니다(issue #22, #23 설계). **D3D8 HLE가 추적(`REXBOX_D3D8_TRACE`)이 꺼져 있을 때 추적 문장을 만들지 않습니다. 객체마다 불리는 `SetModelView`·`SetVertexShaderInput`의 서식 비용이 사라집니다.**

| [#23](https://github.com/reexec/rexbox/issues/23) | 그리기 하나의 CPU 비용: 설계만(구현 전, issue는 열린 채) | `30a97b0` |

### 바뀐 것

* **추적 문장**([설계 i022](../design/20261021-i022-trace-text-off-path.md)): `SetModelView`는 호출마다 실수 다섯 개를 `%g`로 쓰고 추적용으로 행렬을 곱했고, `SetVertexShaderInput`은 문자열 두 개를, 텍스처 업로드는 문자열 두 개를 만들었다. 세 곳 모두 `D3d8TraceEnabled()` 안으로 옮겼다. 동작(그림)은 바뀌지 않는다. `TraceOnce` 주석에 호출·그리기마다 지나는 곳은 먼저 검사한다는 규칙을 적었다.
* **설계**([i023 그리기 CPU 비용](../design/20261021-i023-draw-cpu-cost.md)): 그리기 하나에 약 18 µs인 비용을 앞 그리기 이후 바뀐 것만 하도록 줄이는 설계(상태 메모, uniform 캐시, 인덱스·정점·VAO 재사용)와 다음 단계인 렌더 스레드.

## rexbox v0.0.9 (English)

Changes since **v0.0.8** (issue #22, design for #23). **The D3D8 HLE no longer builds trace text while tracing (`REXBOX_D3D8_TRACE`) is off, removing the formatting cost of `SetModelView` and `SetVertexShaderInput`, which titles call per object.**

Issues: #22, no D3D8 trace text while tracing is off (design, work order, implementation, work log; `9f7621b`); #23, the CPU cost of one draw: design only (not implemented, the issue stays open; `30a97b0`).

Changes: trace text ([design i022](../design/20261021-i022-trace-text-off-path.md)): `SetModelView` wrote five floats with `%g` and multiplied matrices for the trace on every call, `SetVertexShaderInput` built two strings, and texture upload two more; all three now sit inside `D3d8TraceEnabled()`, with no change in behaviour (the picture), and `TraceOnce`'s comment states that sites reached per call or draw check first. Design ([i023 draw CPU cost](../design/20261021-i023-draw-cpu-cost.md)): cutting the about 18 µs per draw to what changed since the previous draw (a state memo, a uniform cache, index, vertex and VAO reuse), with a render thread as the next step.

Consumers: no contract change; rebuild without regeneration.

Verified: Win32 x86 Release in the consumer reCT3's tree with no build errors, CTest reCT3 5/5 and rexbox 3/3. reCT3 driving: ucrtbase 13.2% → 2.7% of samples over the same span and samples per frame 20.5 → 17.3; in paired runs `other` 15.6 → 12.1 ms and CPU 27.2 → 24.7 ms per frame. Linux is **not verified**: CI's Linux x86 job fails while installing packages, as since v0.0.3.

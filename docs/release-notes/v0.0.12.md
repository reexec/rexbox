## rexbox v0.0.12

이전 릴리스 **v0.0.11** 이후의 변경입니다(issue #26 후속). **v0.0.11에서 생성 코드가 없는 타이틀 트리(게임 데이터 없는 CI)의 앱이 링크되지 않던 문제를 고쳤습니다.**

### issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#26](https://github.com/reexec/rexbox/issues/26) | 생성 코드가 없을 때의 레지스터 접근 함수와 그 probe | `0290ed4` 및 이 릴리스 커밋 |

### 바뀐 것

* **`src/recomp/recomp_abi_none.c`**: 레지스터 접근 함수(`include/rexbox/recomp/recomp_abi.h`)를 lifter 헤더 없이 정의한다. `GEN_DIR`에 생성 코드가 없으면 `rexbox_add_recompiled_library`가 이것을 `<target>_abi`로 타이틀에 링크한다. `<target>`은 여전히 만들지 않는다.
* **`rexbox_recomp_probe`**(8개 검사): 빈 `GEN_DIR`로 `rexbox_recomp`를 링크해 이 경로를 CI에서 확인한다.

### 소비자가 할 일

* 없다. v0.0.11 대신 이 버전으로 올린다. 게임 데이터 없는 트리에서도 앱이 링크된다.

### 확인한 것

| 구성 | 확인 |
|---|---|
| rexbox Win32 x86 Debug | 경고 0, CTest 4/4(`rexbox_recomp_probe` 8/8) |
| reCT3, 빈 `RECT3_RECOMP_GEN_DIR`, Win32 x86 Debug | `rect3.exe` 링크, CTest 6/6 |

## rexbox v0.0.12 (English)

Changes since **v0.0.11** (follow-up to issue #26). **Fixes v0.0.11's link failure for an application in a title tree with no generated code (a CI without game data).**

Issue: #26, register accessors without generated code and their probe (`0290ed4` and this release's commit).

Changes:
* `src/recomp/recomp_abi_none.c` defines the register accessors (`include/rexbox/recomp/recomp_abi.h`) without the lifter's header. When `GEN_DIR` has no generated code, `rexbox_add_recompiled_library` links it into the title as `<target>_abi`; it still makes no `<target>`.
* `rexbox_recomp_probe` (8 checks) links `rexbox_recomp` with an empty `GEN_DIR`, so CI covers this path.

Consumers: nothing to do beyond moving to this version instead of v0.0.11. Applications now link in a tree without game data.

Verified:
* rexbox Win32 x86 Debug: 0 warnings, CTest 4/4 (`rexbox_recomp_probe` 8/8).
* reCT3 with an empty `RECT3_RECOMP_GEN_DIR`, Win32 x86 Debug: `rect3.exe` links, CTest 6/6.

## rexbox v0.0.26 (English)

The changes since **v0.0.25** (issues #71, #72). **`REXBOX_DSOUND_TRACE` gains per-stream packet statistics and signal levels, and `REXBOX_AUDIO_DUMP` saves the output as WAV.** These are diagnostics for sound problems (the music in reexec/reEXCEED#9).

Issues:
- #71: per-stream packet statistics (submitted, mixed, completed, starved, paused, flushes, discontinuities, the last delivery), the first eight `Process`, `Pause`, `Flush` and `Discontinuity` calls, and a report every five seconds (`af9a191`).
- #72: `REXBOX_AUDIO_DUMP=<file>` writes the output WAV (48 kHz, 2 ch, 16 bit); per-stream peaks before and after gain, the output peak, and the number of buffers playing (`501e699`).

For consumers: **no code change is needed.** Both work only when their environment variable is set.

Verified:
- Win32 x86 Debug and Release (in the reEXCEED tree): 0 errors and 0 warnings, CTest 7/7, `rexbox_dsound_probe` 84 checks (73 → 84).
- In reEXCEED, song select → gameplay → GAME OVER records the stream statistics, the peaks and the WAV dump.

These were implemented in another session (implemented by Antigravity, designed and reviewed by Claude) and moved onto v0.0.25 before the merge.

## rexbox v0.0.28 (English)

The changes since **v0.0.27** (issue #78). **Every draw uses one vertex array (VAO).** The VAO per cached vertex range (#23) cost several ms per frame in dense scenes, because the driver validates each VAO.

Issue: #78, the per-range VAOs are removed and draws go through the one stream VAO, decided after comparing both with an experiment switch (`198d97c`, `158477e`).

For consumers: **no code change and no setting.** The experiment switch `REXBOX_GL_VAO` was removed after the decision.

Verified: rexbox CTest 4/4 and Python tests 6/6; reCT3 Win32 x86 Release with 0 warnings and CTest 7/7. In the dense driving stretches (1230–1300 draws) the game ran at 59.2–59.3 fps with 8.3–8.9 ms of CPU and 0.9 ms of GL per frame, against 54–57 fps, 12.7–14.3 ms and 4.1–4.6 ms before.

Implemented by Antigravity; designed, reviewed and measured by Claude.

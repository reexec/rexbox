## rexbox v0.0.25 (English)

The changes since **v0.0.24** (issue #73). **Draws with a pixel shader that the title made through its own library code now render.**

Issue #73: a pixel shader handle missing from the HLE's table that is the library's object in guest memory draws with the definition at `[handle + 8]` (`9731739`).

For consumers: **no code change is needed.** Draws that were skipped ("with unknown pixel shader … is not drawn") now render.

Verified:
- Win32 x86 Debug and Release (in the reEXCEED tree): 0 errors and 0 warnings, CTest 7/7.
- In reEXCEED, locked songs' pictures and preview on the song select come out grey as in xemu (the user's check).

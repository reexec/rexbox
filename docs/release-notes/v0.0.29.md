## rexbox v0.0.29 (English)

The changes since **v0.0.28** (issues #80, #81). **`REXBOX_D3D8_SLOW_FRAME`'s slow-frame report shows in more detail what a long frame spent its time on.** These are diagnostics for reexec/reCT3#41 (frame pacing).

Issues: #80, the presenting thread's waits (kernel waits, critical sections, host guest locks) and file reads on the slow-frame line (`6793062`); #81, one line under a slow frame per texture upload (reason, size, decode and GL time) and per new program (first draw, setup, how it was made) (`ebecbc5`).

For consumers: **no code change is needed.** The data is collected only with `REXBOX_D3D8_SLOW_FRAME` set; the default path checks one flag.

Verified: rexbox CTest 4/4; reCT3 Win32 x86 Release with 0 warnings and CTest 7/7. In drives it showed the loading frames' file reads, the artifact stalls of writing the profile's reports, and that uploads are a small cause during driving.

Implemented by Antigravity; designed, reviewed and measured by Claude.

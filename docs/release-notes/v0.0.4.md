#7은 XDK 4531 D3D8 커버리지 전체를 다루므로 열어 둔다.

### 바뀐 것

* **포그**([설계 i007-fog-vertex-blend](../design/20261020-i007-fog-vertex-blend.md)): XDK 4531 상태 내보내기의 규칙을 따른다. 좌표는 PLANAR(눈 공간 z, 부호 유지), RADIAL, NONE(specular alpha), XYZRHW(w), 정점 프로그램(oFog)이다. 계수는 LINEAR, EXP, EXP2 또는 정점 값이고, 고정 기능 프래그먼트 끝에서 포그 색과 섞는다. 픽셀 셰이더의 `FOG` 레지스터 alpha에 계수를 둔다.
* **정점 블렌딩**: `SetVertexBlendModelView`의 모델뷰를 모두 보관하고, `D3DRS_VERTEXBLEND`(NV2A 스킨 모드 1..6)에 따라 행렬 2~4개로 위치와 법선을 가중합한다. 가중치는 FVF `XYZB*` 또는 declaration 레지스터 1이다(float, `PBYTE`, `NORMSHORT`).
* 순수 함수 `d3d8_fog_blend.{h,cpp}`. probe d3d8 220개.

## rexbox v0.0.4 (English)

Changes since **v0.0.3** (progress on issue #7). **The D3D8 HLE draws fog and vertex blending.**

Issue: #7, fog and vertex blending (design and work order, implementation; `0240f03`, `c4999d9`); #7 covers all of XDK 4531's D3D8 coverage and stays open.

Changes: fog follows XDK 4531's state flush ([design i007-fog-vertex-blend](../design/20261020-i007-fog-vertex-blend.md)), with the coordinate from PLANAR (eye-space z, sign kept), RADIAL, NONE (specular alpha), XYZRHW (w) or vertex programs (oFog), the factor LINEAR, EXP, EXP2 or the vertex's value, blended towards the fog colour at the end of the fixed-function fragment, and carried in the alpha of a pixel shader's `FOG` register; vertex blending keeps all of `SetVertexBlendModelView`'s model views and, by `D3DRS_VERTEXBLEND` (NV2A skin modes 1..6), sums position and normal over two to four matrices with weights from FVF `XYZB*` or declaration register 1 (float, `PBYTE`, `NORMSHORT`); pure functions in `d3d8_fog_blend.{h,cpp}`; the d3d8 probe at 220 checks.

Consumers: no contract change.

Verified: Win32 x86 Debug in the reCT3 tree with no build errors and `ctest` passing (probes 83 / 55 / 220); reCT3 builds blending (two to four matrices) and fog programs with no shader error or "not drawn" report, and its attract demo draws correctly; Linux is checked by this pull request's CI.

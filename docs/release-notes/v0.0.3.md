## rexbox v0.0.3

이전 릴리스 **v0.0.2** 이후의 변경입니다(issue #8, #10, #12, 그리고 #7·#9의 진행분). **XDK 4531 타이틀(Crazy Taxi 3, reexec/reCT3)이 이 런타임으로 부팅해 어트랙트 데모를 3D로 그립니다.**

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#8](https://github.com/reexec/rexbox/issues/8) | 게스트 메모리의 물리 메모리 창(0x80000000, 0xF0000000) | `034c84f` |
| [#10](https://github.com/reexec/rexbox/issues/10) | `regenerate.py`: `hle_libraries.json`의 `lifted` 목록 | `034c84f` |
| [#12](https://github.com/reexec/rexbox/issues/12) | 발화하는 커널 타이머, DPC 실행, `KeWaitForMultipleObjects` | `98d7398`, `97a8721` |

진행 중(열어 둠): [#7](https://github.com/reexec/rexbox/issues/7) D3D8 4531 커버리지(`82f7714`, `c4e6a09`, `e5aa2e3`, `6ea8bd1`, `bf34d41`, `83536aa`, `ed2a8c1`; 포그와 정점 블렌딩이 남음), [#9](https://github.com/reexec/rexbox/issues/9) DSOUND 4531 커버리지(`93d3b71`, `d0a8f4a`, `6bb1a52`, `879a2c5`).

### 바뀐 것

* **게스트 메모리**: `GuestMemory::Options::physical_window`, 플랫폼 계약 `AllocateGuestSpace`([설계 i008](../design/20261020-i008-physical-window.md)).
* **커널**: 타이머 서비스 호스트 스레드가 타이머를 발화시킨다. DPC는 커널 소유 게스트 스레드(예약 ordinal `0x3FF`의 `rexbox_DpcLoop`)에서 IRQL 2로 실행한다. `KeWaitForMultipleObjects`, `StartKernelGuestThread`도 들어갔다([설계 i012](../design/20261020-i012-kernel-timers-dpc.md)).
* **D3D8**: 투영-뷰포트 행렬, `SetModelView`, `SetVertexShaderInput`, `SetVertexBlendModelView`(첫 행렬), `Suspend`. 푸시 버퍼 `BeginPush`/`EndPush`는 `SET_BEGIN_END`, `INLINE_ARRAY`, `ARRAY_ELEMENT16/32`를 해석한다([설계 i007-push-buffer](../design/20261020-i007-push-buffer.md)). 바인딩된 변수로 유도하는 렌더 상태 배치(논리 ID와 슬롯 API), `D3D_g_Stream` 없이도 확정되는 전역, `SetRenderState_Simple`의 NV2A 메서드 → 상태 저장, `CreatePalette`/`SetPalette`와 P8, `D3DVSDT_NORMPACKED3`, declaration만 있는 셰이더의 고정 기능 그리기([설계 i007-render-state-4531-palette](../design/20261020-i007-render-state-4531-palette.md)).
* **DSOUND**: `DirectSoundCreateBuffer`, `CDirectSound_*`, `SetFormat`, `SetPitch`, `SetMixBinVolumes_8`, `StopEx`, `SetRolloffCurve`, `XAudioCalculatePitch`, `DownloadEffectsImage`, HRTF 설정.
* **probe**: kernel 83, dsound 55, d3d8 201개.

### 소비자가 할 일

* `RenderStateValue`/`SetRenderStateValue`는 이제 **논리 ID**(`rs::k*`, 4134 번호)를 받는다. 타이틀이 넘기는 `D3DRENDERSTATETYPE`은 `SetRenderStateSlot`으로 쓴다.
* 4531처럼 `D3D_g_Stream`이나 `D3D_InitializeDeviceState`가 식별되지 않는 빌드는 타이틀 프로파일이 주소를 바인딩한다(reCT3 `ct3_profile.cpp` 참고).
* 물리 창이 필요한 타이틀은 `GuestMemory::Options::physical_window`를 켠다.

## rexbox v0.0.3 (English)

Changes since **v0.0.2** (issues #8, #10, #12, and progress on #7 and #9). **An XDK 4531 title (Crazy Taxi 3, reexec/reCT3) boots on this runtime and draws its attract demo in 3D.**

Resolved: #8, the physical memory windows at 0x80000000 and 0xF0000000 (`034c84f`); #10, the `lifted` list of `hle_libraries.json` for `regenerate.py` (`034c84f`); #12, kernel timers that fire, DPC delivery and `KeWaitForMultipleObjects` (`98d7398`, `97a8721`). Still open: #7, D3D8 4531 coverage (`82f7714`, `c4e6a09`, `e5aa2e3`, `6ea8bd1`, `bf34d41`, `83536aa`, `ed2a8c1`; fog and vertex blending remain), and #9, DSOUND 4531 coverage (`93d3b71`, `d0a8f4a`, `6bb1a52`, `879a2c5`).

Changes: guest memory gains `GuestMemory::Options::physical_window` and the platform contract `AllocateGuestSpace` ([design i008](../design/20261020-i008-physical-window.md)); the kernel fires timers from a timer-service host thread, runs DPCs at IRQL 2 on a kernel-owned guest thread (`rexbox_DpcLoop` at the reserved ordinal `0x3FF`), and gains `KeWaitForMultipleObjects` and `StartKernelGuestThread` ([design i012](../design/20261020-i012-kernel-timers-dpc.md)); D3D8 gains the projection-viewport matrix, `SetModelView`, `SetVertexShaderInput`, `SetVertexBlendModelView` (first matrix), `Suspend`, push buffers through `BeginPush`/`EndPush` interpreting `SET_BEGIN_END`, `INLINE_ARRAY` and `ARRAY_ELEMENT16/32` ([design i007-push-buffer](../design/20261020-i007-push-buffer.md)), a render-state layout derived from bound variables (logical IDs and a slot API), globals settled without `D3D_g_Stream`, `SetRenderState_Simple` storing states from their NV2A methods, `CreatePalette`/`SetPalette` with P8, `D3DVSDT_NORMPACKED3`, and fixed-function drawing for declaration-only shaders ([design i007-render-state-4531-palette](../design/20261020-i007-render-state-4531-palette.md)); DSOUND gains `DirectSoundCreateBuffer`, the `CDirectSound_*` forms, `SetFormat`, `SetPitch`, `SetMixBinVolumes_8`, `StopEx`, `SetRolloffCurve`, `XAudioCalculatePitch`, `DownloadEffectsImage` and the HRTF settings; the probes report kernel 83, dsound 55 and d3d8 201 checks.

Consumers: `RenderStateValue`/`SetRenderStateValue` now take **logical IDs** (`rs::k*`, 4134 numbers), and a `D3DRENDERSTATETYPE` from the title goes through `SetRenderStateSlot`; a build that leaves `D3D_g_Stream` or `D3D_InitializeDeviceState` unidentified, as 4531 does, has its title profile bind the addresses (see reCT3's `ct3_profile.cpp`); a title that needs the physical windows turns on `GuestMemory::Options::physical_window`.

Verified: Win32 x86 Debug in the reCT3 tree with no build errors and `ctest` passing (the three rexbox probes included); reCT3 v0.0.2 boots, shows its title screen and the attract demo in 3D (hidden-display frame dumps); on Linux the #8 part was checked on x64 and x86 Debug/Release, and later changes are checked by this pull request's CI.

## rexbox v0.0.2

이전 릴리스 **v0.0.1** 이후의 변경입니다(issue #4). **Linux x64와 x86이 두 번째 호스트로 준비되었습니다: POSIX 플랫폼 계층, CMake 프리셋, Linux CI.**

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#4](https://github.com/reexec/rexbox/issues/4) | Linux x64 / x86 준비: POSIX 플랫폼 계층, 프리셋과 빌드 스크립트, Linux CI | (이 PR의 squash 커밋) |

### 바뀐 것

* **Linux 플랫폼 계층**([설계 i004](../design/20261020-i004-linux-preparation.md)): `src/platform/linux/`가 가상 메모리(mmap, soft-dirty 페이지 추적), 보호 호출(C++ 예외와 신호), 호스트 스레드, 시스템 정보를 구현한다. 샘플러(`REXBOX_SAMPLE`)는 아직 거부한다.
* **x86 부동소수점**: `rexbox_apply_host_flags()`가 32비트 x86의 GCC/Clang에 `-msse2 -mfpmath=sse`를 건다(x87 확장 정밀도 배제; 소비자에게도 적용).
* **빌드 진입점**: `CMakePresets.json`의 `linux-{x64,x86}-{debug,release}`, `scripts/build_linux.sh`.
* **CI**: `ci.yml`과 `release.yml`에 ubuntu-24.04의 x64/x86 × Debug/Release 잡.
* XbSymbolDatabase 타깃에 `-Wno-error=stringop-overread`(GCC `-m32 -O2`), `d3d8_resource.cpp`의 미사용 함수 삭제.

### 소비자가 할 일

* 계약 변경 없음. Linux 앱을 만들려면 rexbox의 프리셋과 같은 의존 패키지로 빌드한다(`docs/guides/linux-setup-and-build.md`).

### 확인한 것

| 구성 | 확인 |
|---|---|
| Linux x64 / x86 Debug / Release (WSL2 Ubuntu 24.04, GCC 13) | 빌드 경고 0, `ctest` 3/3 |
| Win32 x86 Debug | 빌드 경고 0, `ctest` 3/3 |

## rexbox v0.0.2 (English)

Changes since **v0.0.1** (issue #4). **Linux x64 and x86 are prepared as the second host: a POSIX platform layer, CMake presets and Linux CI.**

Resolved: #4 (the Linux preparation; the squash commit of this pull request). Changes: `src/platform/linux/` implements virtual memory (mmap, soft-dirty page tracking), guarded calls (a C++ exception and signals), host threads and system info, with the sampler (`REXBOX_SAMPLE`) still declining ([design i004](../design/20261020-i004-linux-preparation.md)); `rexbox_apply_host_flags()` adds `-msse2 -mfpmath=sse` on 32-bit x86 GCC/Clang (no x87 excess precision; consumers get it too); the `linux-{x64,x86}-{debug,release}` presets and `scripts/build_linux.sh`; ubuntu-24.04 jobs in `ci.yml` and `release.yml`; `-Wno-error=stringop-overread` on the XbSymbolDatabase target and an unused helper removed.

Consumers: no contract change; a Linux app builds with the same presets and packages (`docs/guides/linux-setup-and-build.md`).

Verified: Linux x64 and x86 Debug/Release on WSL2 Ubuntu 24.04 (GCC 13) with 0 warnings and `ctest` 3/3; Win32 x86 Debug with 0 warnings and `ctest` 3/3.

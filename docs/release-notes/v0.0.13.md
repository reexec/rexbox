## rexbox v0.0.13 (English)

Changes since **v0.0.12** (issue #29). **Removes the two warnings of a Linux GCC build**, one of them a bug that cut the last character off the DPC trace string.

Issue: #29, the DPC trace buffer and the XbSymbolDatabase header warning (`bcc1993`).

Changes:
* `src/hle/kernel/kernel_timer.cpp`: the DPC trace string buffer grows from 16 to 24 bytes (`"routine %08X"` needs 17 with the NUL).
* `tools/xdk_symbols/main.cpp`: the unused static table warning of the third-party header `libXbSymbolDatabase.h` is off around that include, for GCC and Clang only.

Consumers: nothing to do; a Linux GCC build shows no rexbox warnings.

Verified: Linux x64 and x86 Release (GCC 13) with 0 warnings and CTest 4/4; Win32 x86 Release with 0 warnings and probes 94/55/220 with 0 failures. User: approved the merge (the decision in nworkers/reJSRF#119).

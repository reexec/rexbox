## rexbox v0.0.27 (English)

The changes since **v0.0.26** (issue #76). **`REXBOX_GL_CALLS=time` measures the GL driver time per frame by entry point.** It is a diagnostic for sizing reexec/reCT3#41 (the CPU cost of dense scenes).

Issue: #76, `REXBOX_GL_CALLS=time` times every GL call, and each profile window prints a `gl time` line with the total, the number of calls, the timer estimate, the share of cpu and 16 entry points (`6e553d7`).

For consumers: **no code change is needed.** It works only when the variable is set, and `REXBOX_GL_CALLS=1` still counts calls only.

Verified: rexbox CTest 4/4 and Python tests 6/6; reCT3 Win32 x86 Release with 0 warnings and CTest 7/7. In a drive, `glBindVertexArray` took 6.66 ms of the 7.44 ms of GL time per frame in a dense scene (1584 draws).

Implemented by Antigravity, designed and reviewed by Claude.

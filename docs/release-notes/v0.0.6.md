## rexbox v0.0.6 (English)

Changes since **v0.0.5** (issue #16). **The D3D8 texture cache keeps P8 textures per palette.**

Issue: #16, caching P8 textures per palette (design and work order, implementation, work log; `cd54ec7`, `61ffe64`).

Changes: P8 palette variants ([design i016-p8-palette-variants](../design/20261021-i016-p8-palette-variants.md)): each texture header holds a list of variants, for P8 one GL texture per palette `Data` and `Common` (up to 16 per header, least recently used replaced), so drawing one texture with several palettes in turn no longer decodes it again; `MarkTextureWritten`, `ForgetTexture` and `TextureCacheBytes` handle every variant.

Consumers: no contract change.

Verified: Win32 x86 Release with no build errors and `ctest` passing; in reCT3's city scenes 22.0–26.1 fps with `setup` at 5.9–12.4 ms became 27.9–30.0 fps with `setup` at 1.2–2.3 ms, P8 re-uploads went from 13.9–42.3 per frame to 0–0.4, and frame dumps draw each vehicle colour separately. Linux is **not verified**: CI's Linux x86 job fails while installing packages (a `libglib2.0-dev:i386` dependency conflict) and the other Linux jobs are cancelled, as since v0.0.3.

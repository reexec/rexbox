## rexbox v0.0.15 (English)

Changes since **v0.0.14** (issue #33). **The submodule-missing messages name `git submodule update --init --recursive`.** In a consumer project (reJSRF, reCT3) rexbox is itself a submodule, so the non-recursive command the messages named had already been run and did not initialize rexbox's SDL, imgui, smaa and XbSymbolDatabase.

Issue: #33, `--recursive` in the submodule-missing messages (`f7c888b`).

Changes: the four missing-submodule messages in `CMakeLists.txt` (SDL, imgui, smaa, XbSymbolDatabase) name `git submodule update --init --recursive`, which does nothing more in a standalone checkout; `docs/guides/win32-setup-and-build.md` names the same command.

Consumers: nothing to do; no code changed and no regeneration is needed. The consumer reJSRF checks for submodules that are not checked out in its own build scripts before CMake runs (nworkers/reJSRF#121).

Verified: the consumer reJSRF's full Win32 x86 Release build with this `CMakeLists.txt` configures and builds with 0 warnings. User: approved the merge.

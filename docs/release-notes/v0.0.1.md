## rexbox v0.0.1

첫 릴리스입니다(issue #1, #2). **reJSRF v0.0.42의 Xbox 런타임을 이력과 함께 독립 라이브러리로 분리했고, GitHub Actions로 빌드·단위 테스트·태그·릴리스를 검증합니다.**

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#1](https://github.com/reexec/rexbox/issues/1) | reJSRF에서 rexbox 분리, CMake 소비자 계약, upstream xboxrecomp v0.15.0, 일반화한 스크립트, 작업 규칙 | `7feac11`, `633e897`, `807e07a`, `833e05e` |
| [#2](https://github.com/reexec/rexbox/issues/2) | GitHub Actions: CTest 단위 테스트, 태그 검증, 릴리스 노트로 릴리스 생성 | `48bbbe8`, `07ec6e2` |

### 바뀐 것

* **독립 라이브러리**([설계 i001](../design/20261020-i001-project-bootstrap.md)): `add_subdirectory(third_party/rexbox)`로 쓰는 CMake 프로젝트. 소비자 계약은 `REXBOX_XBOXRECOMP_DIR`, `REXBOX_BUILD_TOOLS`, `rexbox_apply_host_flags()`, `rexbox_add_recompiled_library()`, `rexbox_check_license()`, `rexbox_strict_warnings()`.
* **xboxrecomp**: submodule이 upstream v0.15.0을 가리킨다. `rexbox_recomp`는 그 헤더가 요구하는 `g_eflags`, `xbox_Cpuid`, `xbox_PortIn/Out`, `xbox_GuestCpuPreempt`를 정의하고, reJSRF fork의 헤더로도 컴파일된다.
* **타이틀 이름 제거**: 사용자 설정 폴더 이름은 `platform::SetApplicationIdentity`로 앱이 준다.
* **스크립트**: `scripts/recomp/regenerate.py` 등이 타이틀 경로를 인자로 받는다(`run(...)`).
* **Actions**([설계 i002](../design/20261020-i002-github-actions.md)): `ci.yml`(빌드 + `ctest`), `release.yml`(태그가 `VERSION`·`main`과 맞는지 검사, 릴리스 노트가 있으면 소스만 담은 GitHub Release).

### 소비자가 할 일

* reCT3: submodule을 이 태그로 올린다(이미 브랜치 커밋을 쓰고 있었다). 계약 변경 없음.
* reJSRF: 전환은 [nworkers/reJSRF#102](https://github.com/nworkers/reJSRF/issues/102)에서 나중에 진행한다(설계 i001 §6).

## rexbox v0.0.1 (English)

The first release (issues #1, #2). **reJSRF v0.0.42's Xbox runtime split out as a standalone library with its history, and GitHub Actions verifying the build, the unit tests, tags and releases.**

Resolved: #1 (the split, the CMake consumer contract, upstream xboxrecomp v0.15.0, generalized scripts, the working rules; commits `7feac11`, `633e897`, `807e07a`, `833e05e`) and #2 (Actions: CTest unit tests, tag verification, releases from release notes; `48bbbe8`, `07ec6e2`).

Changes: a standalone CMake project used through `add_subdirectory(third_party/rexbox)` with the contract `REXBOX_XBOXRECOMP_DIR`, `REXBOX_BUILD_TOOLS`, `rexbox_apply_host_flags()`, `rexbox_add_recompiled_library()`, `rexbox_check_license()` and `rexbox_strict_warnings()` ([design i001](../design/20261020-i001-project-bootstrap.md)); the xboxrecomp submodule at upstream v0.15.0, with `rexbox_recomp` defining `g_eflags`, `xbox_Cpuid`, `xbox_PortIn/Out` and `xbox_GuestCpuPreempt` and still compiling against reJSRF's fork header; title names gone (`platform::SetApplicationIdentity` names the settings folder); the recompilation scripts taking the title's paths as arguments; `ci.yml` (build + `ctest`) and `release.yml` (tag against `VERSION` and `main`, a source-only GitHub Release when the release note exists; [design i002](../design/20261020-i002-github-actions.md)).

Consumers: reCT3 moves its submodule to this tag (no contract change); reJSRF's migration is deferred to [nworkers/reJSRF#102](https://github.com/nworkers/reJSRF/issues/102).

Verified: Win32 x86 Debug and Release with 0 warnings and `ctest` 3/3; `rexbox_recomp` against the reJSRF fork header; reCT3 building Debug and Release with `ctest` 5/5.

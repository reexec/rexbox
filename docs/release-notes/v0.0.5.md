## rexbox v0.0.5 (English)

Changes since **v0.0.4** (issue #14). **The kernel file HLE renames files.**

Issue: #14, `NtSetInformationFile` `FileRenameInformation` (design and work order, implementation, probe, work log; `2049e2d`, `c0bb5a2`).

Changes: rename ([design i014-file-rename](../design/20261021-i014-file-rename.md)) is `NtSetInformationFile` class 10; `FILE_RENAME_INFORMATION`'s name resolves against its `RootDirectory` by `OBJECT_ATTRIBUTES`' rules (`NameRelativeTo`), `ReplaceIfExists` and read-only devices are honoured, and the streams of every handle open on the host file are closed around the rename and reopened on the new path, so open handles follow the new name; `REXBOX_TRACE_FILES` prints `[kernel] rename`. The kb records `FILE_RENAME_INFORMATION` and how XAPI `MoveFileEx` calls it. The kernel probe is at 94 checks (11 for rename).

Consumers: no contract change.

Verified: Win32 x86 Release with no build errors and `ctest` 3/3 (kernel probe, 94 checks); in reCT3 the temporary file on the cache partition is renamed to its final name and opened, and that asset's geometry draws; Linux is checked by this pull request's CI.

## rexbox v0.0.8

이전 릴리스 **v0.0.7** 이후의 변경입니다(issue #19). **D3D8 펜스 함수 `D3DDevice_InsertFence`, `D3DDevice_BlockOnFence`, `D3DDevice_IsFencePending`에 HLE export가 생겼습니다. 이 함수를 부르는 타이틀이 미구현 HLE로 멈추지 않습니다.**

### issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#19](https://github.com/reexec/rexbox/issues/19) | D3D8 펜스 export(설계·작업 지시, 구현, 작업 로그) | `5463e1c`, `036a602`, `4a54012` |

### 바뀐 것

* **펜스 export**([설계 i019-fence-exports](../design/20261021-i019-fence-exports.md)): rexbox는 그리기를 호출 안에서 끝내므로 펜스는 넣는 순간 지나간 것이다. `InsertFence`는 `D3D_SetFence`와 같은 카운터를 올려 돌려주고, `BlockOnFence`는 바로 돌아오며, `IsFencePending`은 FALSE다.
* **kb**: `xbox-d3d8-api.md` §5에 펜스 항목(4531의 `InsertFence` = `D3D_SetFence(0)`, `BlockOnFence(f)` = `D3D_BlockOnTime(f, 0)`).

### 소비자가 할 일

* 계약 변경 없음. export는 이름으로 묶이므로 재생성 없이 다시 빌드하면 된다.

## rexbox v0.0.8 (English)

Changes since **v0.0.7** (issue #19). **The D3D8 fence functions `D3DDevice_InsertFence`, `D3DDevice_BlockOnFence` and `D3DDevice_IsFencePending` have HLE exports, so a title that calls them no longer stops at an unimplemented HLE function.**

Issue: #19, the D3D8 fence exports (design and work order, implementation, work log; `5463e1c`, `036a602`, `4a54012`).

Changes: fence exports ([design i019-fence-exports](../design/20261021-i019-fence-exports.md)): rexbox finishes drawing inside each call, so a fence has passed once it is inserted; `InsertFence` increments and returns `D3D_SetFence`'s counter, `BlockOnFence` returns at once, and `IsFencePending` is FALSE. The kb `xbox-d3d8-api.md` section 5 gained a fence entry (in 4531, `InsertFence` = `D3D_SetFence(0)` and `BlockOnFence(f)` = `D3D_BlockOnTime(f, 0)`).

Consumers: no contract change; exports bind by name, so a rebuild without regeneration is enough.

Verified: Win32 x86 Release in the consumer reCT3's tree with no build errors and CTest 5/5. Without this change reCT3 stops on thread 2 at `D3DDevice_InsertFence` (`000F5050`) after Start; with it and no `REXBOX_HLE_FALLBACK` it goes through mode selection and West Coast to driving with no unimplemented-HLE stop. `IsFencePending` is **not exercised** (reCT3 does not link it). Linux is **not verified**: CI's Linux x86 job fails while installing packages, as since v0.0.3.

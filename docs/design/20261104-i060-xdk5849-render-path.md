# 설계: XDK 5849 렌더 상태 배치, 없는 specular의 알파, LTCG가 쓰는 디바이스 변환 배열 (issue #60)

상태: **구현됨**. 작업 로그: [20261104-i060](../work-logs/20261104-i060-xdk5849-render-path.md). 소비자: reexec/reEXCEED#4.

## 1. 요구사항

Pump It Up: Exceed(XDK 5849)의 그림이 검었다. 원인은 세 가지였다(모두 **확인됨**, reEXCEED 작업 로그 i004).

## 2. 렌더 상태 배치

* 타이틀의 기본 상태 루틴(`0x0017A1E0`)의 경계: 슬롯 57~165를 돌며 92 미만은 simple(슬롯별 NV2A 메서드 표), 92~135는 deferred(44개), 136~165는 complex(setter 표 30개). 변수 `D3D_g_RenderState` `0x00185A98`, `D3D_g_DeferredRenderState` `0x00185C08`(슬롯 92), `D3D_g_ComplexRenderState` `0x00185CB8`(슬롯 136).
* simple 0~81은 4134와 같은 메서드, 82는 4531의 ZMinMaxControl(`0x1D78`), 83은 새 메서드(`0x147C`), 84~91은 자리 채움.
* deferred: 4134의 35개 뒤에 9개(PresentationInterval과 사용하지 않는 8개, **추정**: Cxbx-Reloaded의 표를 지식으로만 참고).
* complex: 4134의 29개와 같은 순서이고, `SampleAlpha`가 LineWidth와 Dxt1NoiseEnable 사이(인덱스 22)에 끼었다(setter 표의 이름으로 **확인됨**).
* 설계: `RenderStateLayout`에 `complex_count`와 `sample_alpha_index`. deferred는 4134보다 크면 받아들인다(뒤에 붙은 것은 논리 ID 없음). `D3DRS_SampleAlpha` 변수가 있으면 그 슬롯에 논리 ID `rs::kSampleAlpha`(146). 4134보다 작은 deferred는 4134로 돌아간다.

## 3. 없는 specular의 알파

* 고정 기능 셰이더는 FVF에 specular가 없으면 `v_specular = vec4(0)`이었다. D3DFOG_NONE 포그는 specular 알파를 포그 계수로 쓰므로, 포그를 켠 2D 사각형이 모두 포그 색(검정)이 되었다.
* 설계: 없는 specular는 `(0, 0, 0, 1)`. 포그를 켜고도 2D가 보여야 하는 타이틀의 동작과 맞다(**추정**: 실기의 기본 정점 값은 확인하지 않았다).

## 4. 디바이스의 변환 배열

* lift된 `SetTransform`(`0x001732A0`)은 행렬을 `g_pDevice + 0xC60 + State × 64`에 복사하고 더티 비트(`0x00181E58` 표)를 `[0x00185A90]`에 OR한다. LTCG 게임 코드도 같은 것을 인라인한다(`0x00077390`: `+ 0xDE0` = World, State 6). HLE는 world를 받지 못했다.
* 설계: 타이틀이 `D3DDevice__m_Transform_OFFSET`(5849: `0xC60`)을 바인딩하면 그리기 전에 그 배열 10개를 파이프라인으로 읽고(`SyncTransformsFromDevice`), HLE의 `SetTransform`과 상태 블록 Apply가 그 배열에도 쓴다(`StoreTransformToDevice`).

## 5. 검증

* d3d8 probe: 5849 배치 검사(슬롯 92, 136, 166개, FogEnable 92, FillMode 139, ZBias 149, SampleAlpha 158, 왕복), 234개 통과. CTest 7/7.
* reEXCEED: 동영상 프레임이 화면 가운데에 놓이고, 타이틀 화면("PRESS START BUTTON")이 그려진다.

# Design: the XDK 5849 render-state layout, the absent specular's alpha, and the device transform array LTCG writes (issue #60)

Status: **implemented**. Work log: [20261104-i060](../work-logs/20261104-i060-xdk5849-render-path.md). Consumer: reexec/reEXCEED#4.

Pump It Up: Exceed's (XDK 5849) picture was black for three reasons, all **confirmed** (reEXCEED work log i004).

**Render-state layout.** The title's default-state routine (`0x0017A1E0`) walks slots 57..165: below 92 simple (an NV2A method table per slot), 92..135 deferred (44), 136..165 complex (a table of 30 setters); the variables put `D3D_g_RenderState` at `0x00185A98`, the deferred block at slot 92 and the complex block at slot 136. Simple slots 0..81 carry 4134's methods, 82 is 4531's ZMinMaxControl (`0x1D78`), 83 a new method (`0x147C`), 84..91 filler. The deferred block is 4134's 35 followed by nine (PresentationInterval and eight unused, **inferred**: Cxbx-Reloaded's table used as knowledge only). The complex block keeps 4134's 29 in order with `SampleAlpha` inserted between LineWidth and Dxt1NoiseEnable (index 22, **confirmed** by the setter table's names). `RenderStateLayout` gains `complex_count` and `sample_alpha_index`; a deferred block larger than 4134's is accepted (its extra slots have no logical ID), a bound `D3DRS_SampleAlpha` places the new logical ID `rs::kSampleAlpha` (146), and a deferred block smaller than 4134's still falls back to 4134.

**The absent specular.** The fixed-function shader set `v_specular = vec4(0)` for an FVF without specular; D3DFOG_NONE fog takes its factor from the specular alpha, so every 2D quad drawn with fog on came out the fog colour (black). An absent specular is now `(0, 0, 0, 1)`, which matches a title that keeps 2D visible with fog on (**inferred**: the console's default vertex values are not checked).

**The device's transform array.** The lifted `SetTransform` (`0x001732A0`) copies the matrix to `g_pDevice + 0xC60 + State x 64` and ORs a dirty bit (the table at `0x00181E58`) into `[0x00185A90]`; LTCG game code inlines the same (`0x00077390`: `+ 0xDE0`, the world matrix, State 6), so the HLE never received the world matrix. When the title binds `D3DDevice__m_Transform_OFFSET` (`0xC60` in 5849), draws read the array's ten matrices into the pipeline first (`SyncTransformsFromDevice`), and the HLE's `SetTransform` and state-block Apply write the array as well (`StoreTransformToDevice`).

Verification: the d3d8 probe checks the 5849 layout (slots 92 and 136, 166 slots, FogEnable 92, FillMode 139, ZBias 149, SampleAlpha 158, the round trip) and passes 234 checks; CTest 7/7. In reEXCEED the movie frame sits in the centre of the screen and the title screen ("PRESS START BUTTON") draws.

## 다음 세션이 이어갈 것

1. reCT3의 마지막 실행은 첫 프레임 present와 `SetVertexShaderInput`·`SetModelView`를 지나 `D3DDevice_BeginPush_4`(stdcall 1인자, `000F81F0`)에서 멈췄다. 타이틀은 받은 버퍼에 NV2A 명령을 직접 쓴다(첫 호출 지점: 헤더 `0x000417FC` = `SET_BEGIN_END` 1개, 값 primitive, 이어서 정점 DWORD 복사). HLE에는 푸시 버퍼가 없으므로 `BeginPush`/`EndPush`는 설계가 먼저 필요하다(후보: 게스트 scratch 버퍼를 주고 `EndPush`에서 `SET_BEGIN_END`·inline 정점 같은 일부 메서드만 해석해 그리기로 바꾼다).
2. #7의 큰 일: 4531 렌더 상태 번호(deferred·complex 블록 +1, 단순 블록의 추가 상태 하나 **미확정**)를 식별된 `D3DRS_*`/`D3D_g_*RenderState` 변수에서 가져오도록 `d3d8_globals`의 `RenderStateValue`/`SetRenderStateValue`에 매핑을 두고, 4531의 `SetRenderState_*` setter와 `GetProjectionViewportMatrix`, `GetViewportOffsetAndScale`, `SetModelView`, `SetVertexShaderInput`, 팔레트, fence, `BeginPush`/`EndPush` 등을 더한다. 기본 상태 루틴(`D3D_InitializeDeviceState`의 4531 대응)도 찾아야 한다.
3. #9: `IDirectSoundBuffer_SetPitch`, `SetFormat`, `SetMixBinVolumes_8`, `SetRolloffCurve`, `StopEx`, `DirectSoundCreateBuffer`(`CDirectSound_CreateSoundBuffer` 호출), `XAudioCalculatePitch`.
4. PR #11(#8 닫음)은 CI 뒤 머지 대기. 머지 때 `VERSION` 0.0.3과 `docs/release-notes/v0.0.3.md`를 쓴다.

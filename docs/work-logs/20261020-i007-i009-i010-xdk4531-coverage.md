# Work log: XDK 4531 coverage, in progress (issues #7, #9, #10)

No design yet (each issue's body is the requirement); this log records the pieces added on the branch `i008-physical-window` while following reCT3's first runs (reexec/reCT3#3) and where the next session continues. Done: #7 `D3DDevice_GetRenderTarget` (v0.0.2), `D3DBaseTexture_GetLevelCount` and `D3DDevice_GetProjectionViewportMatrix` (the projection times the shader epilogue's c[58]/c[59] viewport mapping; z scale 1 as in rexbox's convention, the hardware's depth-maximum scale **unresolved**), `D3DDevice_SetVertexShaderInput` (12-byte `{VertexBuffer, Stride, Offset}` entries; while Handle is non-zero its declaration and stream 0 replace the current shader's declaration and `SetStreamSource`; reCT3's first calls only turned it off) and `D3DDevice_SetModelView` (the model view replaces world x view, and the composite with the viewport mapping undone replaces the clip transform; in reCT3 the composite equals model view x projection x viewport with difference 0, **confirmed**) and `D3DDevice_BeginPush_4`/`EndPush` (design [i007-push-buffer](../design/20261020-i007-push-buffer.md)); #9 `CDirectSound_DownloadEffectsImage` (stdcall, 5 arguments, sharing `IDirectSound_DownloadEffectsImage`'s body), `IDirectSound_SetMixBinHeadroom`, `DirectSoundUseFullHRTF`/`UseLightHRTF` (accepted), `DirectSoundCreateBuffer` and `CDirectSound_CreateSoundBuffer` (sharing `IDirectSound_CreateSoundBuffer`'s body), with `XAudioDownloadEffectsImage(pszImageName, pImageLoc, dwFlags, ppImageDesc)` kept lifted because it loads the file itself and then calls that method (first wrongly given a 4-argument buffer HLE, corrected after reading the lifted original); #10 the `lifted` list of `hle_libraries.json` (done). PR #11 (closes #8) waits for CI and the merge, with `VERSION` 0.0.3 and `docs/release-notes/v0.0.3.md` written at merge time.
